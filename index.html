Materi HTML

HTML atau HyperText Markup Language digunakan untuk membuat struktur sebuah halaman website.

Contoh

Tag Dasar HTML

  • h1 → membuat judul
  • p → membuat paragraf
  • a → membuat link
  • img → menampilkan gambar
  • button → membuat tombol

Materi CSS

CSS digunakan untuk mengatur tampilan, warna, ukuran dan layout website.

Contoh

CSS Bisa Digunakan Untuk

  • Mengatur warna
  • Mengatur ukuran teks
  • Mengatur jarak
  • Mengatur background
  • Mengatur layout

Materi JavaScript

JavaScript digunakan untuk membuat website menjadi lebih interaktif.

Contoh

JavaScript Digunakan Untuk

  • Membuat tombol interaktif
  • Validasi form
  • Mengubah isi halaman
  • Membuat animasi
  • Mengambil data dari server
